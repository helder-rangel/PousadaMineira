Sistema de gestão operado pelo console, aplicando os principais conceitos estudados na disciplina: classes, objetos, encapsulamento, construtores, herança,
polimorfismo, interfaces, classes abstratas, vetores e exceções.
O sistema possui:
• Um fluxo completo de uso: cadastrar elementos, realizar operações sobre eles - reservar,
atender, registrar, cobrar etc, e apresentar um resumo ou relatório.
• Elementos de tipos diferentes que se comportam de formas diferentes, por exemplo, cada
tipo calcula seu valor, prazo ou pontuação de um jeito próprio.
• Pelo menos uma regra de negócio que pode ser violada pelo usuário, por exemplo, vaga
esgotada ou horário indisponível. Quando isso acontecer, o sistema deve lançar a
exceção personalizada exigida.
